Why open AI?

GhostMemory AI uses an open-weight model instead of sending personal memories to a closed AI service. The model runs locally in the browser, giving the user more control over their data and the technology behind the experience.

🌐

No AI API bill

There is no per-request commercial AI API in this project. Once the model has been downloaded and cached, inference happens on the user's device.

🧠

Swappable intelligence

Because the application is built around an open model interface, the model can be replaced with another compatible open model as the project evolves.
